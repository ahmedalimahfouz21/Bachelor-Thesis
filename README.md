## Abstract

The purpose of this thesis is to integrate and synchronize an embedded NIOS
CPU called the Effectuator into the Simulink model of a three-dimensional
axes hardware system called demonstrator. The thesis reviewed the previ
ous work related to this project. The integration process started with an
implementation of UDP communication for both the Effectuator and the
demonstrator. With the communication implementation, the Effectuator
was inserted into the common working area of the demonstrator, where all
axes can share their coordination data. After that, motion control algorithms
were implemented to actuate X2-axis. This axis will be driven by the Ef
fectuator to superimpose the motion of the X-axis of the demonstrator. As
a result, the demonstrator was extended by a new transitional axis, and an
agent integration criteria were implanted and tested so more agents can be
integrated with the same procedure.

Keywords : UDP communication, embedded systems, decentralization,
synchronization, motion control
